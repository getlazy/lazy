# Lazy Teams screens

Lazy Teams is a web app where a team runs Lazy tasks together. It is in **private alpha**, so screens and labels may change.

This section has one page per main screen. Each page shows the screen and then lists its regions and controls. For how to use Lazy Teams rather than what is on each screen, see the guides on [builders](../../lazy-teams-builders.md), [agents](../../lazy-teams-agents.md), [environment variables and files](../../lazy-teams-environment.md), [reviewing a task](../../lazy-teams-task-review.md) and [Slack rooms](../../slack-rooms.md).

## Navigation

The top bar shows where you are: **Lazy Teams**, then the team, then the project. Inside a project it links to **Review**, **Builders**, **Clusters**, **Tasks**, **Run**, **Raised**, **Search**, **Settings** and **Messages**. Your account is behind the round avatar at the right.
